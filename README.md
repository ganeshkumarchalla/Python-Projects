# Python Projects

This repository brings together multiple small Python learning projects into one organized workspace.

## Included projects

- `projects/firstpythonprogram` — a simple greeting program
- `projects/bandnamegenerator_1` — a band name generator built from city and pet name inputs
- `projects/Bill Calculator ` - a Bill Calculator That Gives Finall Bill Amount After Tip And also After spliting 

## Structure

```text
Python-Projects/
├── README.md
├── .gitignore
├── pyproject.toml
├── projects/
│   ├── firstpythonprogram/
│   │   ├── README.md
│   │   └── main.py
│   └── bandnamegenerator_1/
│   |    ├── README.md
│   |    └── main.py
|   └── Bill Calculator/
|   |   ├──README.MD
|   |   └── main.py   
└── shared/
```

This layout makes it easy to add more Python projects later without creating a brand-new repository each time.

## Running a project

From the repository root, run any project directly:

```bash
python projects/firstpythonprogram/main.py
python projects/bandnamegenerator_1/main.py
python projects/bill calculator/main.py
```

## Future expansion

Add more folders under `projects/` whenever you build a new Python application. The project repository remains a single home for all your Python learning and experiments.
