# Tip Calculator

## Description
This is a Tip Calculator which calculates the tip as well as splitting of bill between friends.

## Features
- Calculate tip based on bill amount and tip percentage
- Split the total bill (including tip) among multiple friends
- Simple and user-friendly interface

## Language
- Python

## Getting Started

### Prerequisites
- Python 3.x

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/ganeshkumarchalla/Python-Projects.git
   cd Python-Projects/projects/Tip-Calculator
   ```

### Usage
Run the Tip Calculator:
```bash
python tip_calculator.py
```

## How It Works
1. Enter the bill amount
2. Enter the tip percentage
3. Enter the number of people to split the bill
4. The calculator will show:
   - Tip amount
   - Total bill (bill + tip)
   - Amount per person
